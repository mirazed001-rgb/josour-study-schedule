# 📋 منظومة جدول المدارسة الأسبوعي المستقر

## 📚 المقررات المعتمدة:
1. **العقيدة السنوسية (أم البراهين)** — 4 مجالس صباحية (13.5 ساعة).
2. **تنقيح الفصول في الأصول للإمام القرافي** — 3 مجالس صباحية (11.0 ساعة).
3. **قصة الإيمان للشيخ نديم الجسر** — 4 مجالس مسائية (5.0 ساعات).
4. **علم المنطق وتحرير القواعد** — مجلس مسائي (ساعتان).
5. **مراجعة المقولات العشر والتحضير العام** — مجلس ظهيرة (3 ساعات).
